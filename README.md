#Gestion Vendeur
##Description
**Gestion Vendeur** est une application Android native développée dans le cadre d'un **projet académique** pour l'apprentissage du développement Android native avec Java.

L'application permet de gérer une table de vendeurs avec les fonctionnalités suivantes :
-Création
-Lecture
-Mise à jour
-Suppression
-Recherche

##Stack technique
-Android Studio
-Java
-SQLite
